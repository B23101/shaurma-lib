# bend_test — перевірка згину ліктів і колін

Скопіюй теку `bend_test` у `<тека гри>/shaurma_anim/` (або запакуй у zip), у грі F3+T, потім:

    /sanim play bendtest:bend_cycle     # цикл 4 с: 0° → 90° → 150° → згин+вбік/twist → 0°
    /sanim play bendtest:bend_hold_90   # статично 90° — роздивитись лікоть/коліно з усіх боків

Що перевірити: нема щілин на ліктях/колінах; рукави й штани гнуться разом зі шкірою; світло на нижній
частині не «чорніє»; після зупинки кліпа модель рівно ванільна. Предмет у руці й броня — етап 3 (ще не йдуть за згином).
