# Blockbench-плагін «Shaurma Animations»

Встановлення: Blockbench → File → Plugins → *Load Plugin from File* → `shaurma_anim.js`.

Анімація гравця = сцена: риг + окремі моделі (аптечка, бинт, шприц, ефекти), що існують лише в кліпі.
Не предмети слотів — у грі вони там само, як у Blockbench.

| Дія | Де |
|---|---|
| **Shaurma: модель у анімацію** — `.bbmodel` / `.geo.json` з текстурами (і анімацією моделі), прив'язка до кістки або вільно; у руці — поза з Display моделі, як ванільний предмет | File → Import, Animation |
| **Shaurma: підігнати пропс** — масштаб, зсув, поворот з живим переглядом у сцені (відкривається одразу після імпорту) | ПКМ на групі, Edit, Animation |
| **Shaurma: передати пропс в іншу кістку** (бинт: права → ліва рука з кадру) | Animation, ПКМ на групі |
| Shaurma: показати / сховати пропс з цього кадру | Animation, ПКМ на групі |
| Export Shaurma Animation — у resources мода, **одразу в гру** (`<гра>/shaurma_anim/`) або .zip (не розпаковувати — рушій читає архів сам); автоекспорт при Ctrl+S | File → Export |
| **Shaurma: експорт вибраної анімації** (Ctrl+Alt+Shift+E) — пише лише її файл, решту не чіпає | File → Export, Animation |
| Shaurma: швидкий експорт (Ctrl+Alt+E) | File → Export, Animation |
| Shaurma: налаштування анімації — **Тип**: повна / часткова / синхронна / стан (+ предмет у руці, сила руху), fade, погляд, перша особа | Animation |
| Shaurma: налаштування пропса (ховати предмет у руці, світіння, прозорість, предмет гри) | ПКМ на групі / Edit |
| Shaurma: створити риг гравця / скін гравця (PNG) | Animation |
| **Shaurma: модель гравця** — новий проєкт з ригом (кілька текстур, UV по гранях) | Стартовий екран / File → New |

Пропс = група під кісткою ригу (`right_item`, `left_item`, `head`…), яка сама не є кісткою ригу,
або група в корені сцени без ригу всередині — **вільний** пропс (`parent: world`, ефекти навколо гравця).
Експорт пише в `resources/`:
`assets/<ns>/shaurma_anim/player/<тека>/<анімація>.json` (за замовчуванням **кожна анімація гравця — окремий файл**; галочка «окремий файл» у діалозі експорту вимикає це — тоді один `player/<файл>.json`; id кліпа від файлу не залежить), `assets/<ns>/shaurma_anim/props/<пропс>.geo.json`,
`assets/<ns>/textures/shaurma_anim/<пропс>.png`. Кириличні імена груп транслітеруються (`Аптечка` → `aptechka`).

Тест без Blockbench: `node test/export.test.js <папка>` (53 перевірки: експорт, імпорт .geo.json/.bbmodel,
атлас текстур, імена, перенесення анімації моделі), потім
`java dev.shaurmalib.anim.PluginExportCheck <папка>` — вихід читає той самий рушій, що й гра
(зокрема: імпортована й переекспортована модель дає ті самі вершини й UV; вільний пропс).
