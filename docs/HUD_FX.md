# HUD-ефекти (`dev.shaurmalib.forge.fx.hud.HudFx`)

Процедурні 2D-ефекти поверх HUD для будь-якого режиму. Чиста геометрія `POSITION_COLOR`
через `GuiGraphics`: без пост-шейдерів, тому працює з Iris/Oculus, у VR і на слабких ПК.
Кольори — `0xRRGGBB`, прозорість окремим `float` 0..1, час — секунди реального часу.

| Метод | Що малює | Типове застосування |
|---|---|---|
| `line(g, x1, y1, x2, y2, width, rgb, a1, a2)` | товста лінія під будь-яким кутом зі згасанням альфи | сигіли, шеврони, тріщини |
| `disc(g, cx, cy, r, rgb, aIn, aOut)` | диск із м'яким краєм | точки-маркери, жар, краплі |
| `ringTimer(g, cx, cy, r, thickness, fraction, rgb, a)` | дуга від 12 години, частка 0..1 | залишок часу ефекту/позначки |
| `edgeFrame(g, w, h, rgb, a, depthFrac)` | м'яка рамка по всіх краях | віньєтки станів («дупло», загроза) |
| `edgeVeins(g, w, h, rgb, a, time, seed, growth)` | розгалужені прожилки від країв | коріння, вени, тріщини льоду |
| `speedLines(g, w, h, rgb, a, time, count)` | радіальні лінії швидкості | ривок, падіння, прискорення |
| `edgeWave(g, w, h, rgb, a, phase)` | хвиля від країв до центру, фаза 0..1 | «спалах» підключення/позначки |

```java
float t = (System.currentTimeMillis() % 1_000_000L) / 1000f;
HudFx.edgeVeins(g, w, h, 0x7BD34A, 0.30f, t, 42L, 0.6f);     // зелені корені з країв
HudFx.ringTimer(g, 22, h - 62, 9.5f, 2f, left / 200f, 0xFFB347, 0.95f);
HudFx.speedLines(g, w, h, 0xFFFFFF, 0.22f, t, 44);
```

`seed` фіксує форму прожилок між кадрами — вони «дихають», а не стрибають. Перед малюванням
підніміть шар (`g.pose().translate(0, 0, 1800)`), якщо ефект має бути поверх інших оверлеїв.

Приклад режиму — `maniac_shaurma/.../client/mark/DeathwoodHud.java` (маркери позначок, рамка
позначеного, «дупло», лінії ривку, емблема ока).
